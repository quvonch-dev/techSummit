# Eventor Style Conference Landing Page

Bu loyiha Colorlib Eventor sahifasidan ilhomlangan HTML/CSS/JavaScript practice project.

## Fayllar
- `index.html` — asosiy HTML
- `style.css` — barcha dizayn va responsive kodlar
- `script.js` — mobile menu, countdown, schedule filter, theme toggle

## Ishlatish
1. Papkani VS Code bilan oching.
2. `index.html` faylini Live Server orqali ishga tushiring.
3. Rasmlar internetdan olinadi, shuning uchun browser online bo‘lsa yaxshi ko‘rinadi.
